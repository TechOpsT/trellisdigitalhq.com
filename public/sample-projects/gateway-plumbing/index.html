Gateway Plumbing & Heating is a fictional St. Louis home-services shop. This page shows a customer asking for a quote or a visit, and the office keeping that request on one list. It is a sample project, not a client. Nothing on this page is a result, a review, or a real booking.

Two ways a request can come in

Phone tag and paper forms

The customer calls. If the shop is out on a job, the request waits in voicemail, a text, or an email. Someone writes it on a paper form or a notepad. Calling back depends on remembering which notes still need an answer.

An online quote or visit request

The customer enters the job, can attach a photo, and picks a few times. The request shows up on a list marked New, Quoted, Scheduled, or Done. A confirmation is ready to show, and a reminder can appear if a new request is still waiting.
